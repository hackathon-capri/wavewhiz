
# WaveWhiz - Hackathon
Nosso site conecta vendedores e clientes do Capri, em São Francisco do Sul, fortalecendo o comércio local, valorizando moradores e promovendo o desenvolvimento. Mais que uma plataforma de compras, é um espaço que une história, cultura e belezas naturais, dando visibilidade à região e incentivando oportunidades para toda a comunidade. 

Desenvolvedoras: Ana Paula Dominoni, Anna Flávia Silva Carneiro, Emilly Vitória Duarte Ropelato, Kelly Patricia Alves, Pietra Giovana da Silva Lavina.
